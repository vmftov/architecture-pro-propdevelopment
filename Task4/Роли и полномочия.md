> Чтобы не дублировать списки ресурсов в доменных ролях используются шаблонные кластерные роли, но привязка осуществляется через RoleBinding к конкретным пространствам имён.

| Роль                                     | Права роли                                                                                        | Группы пользователей          |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------- | ----------------------------- |
| ClusterRole `security-spec-cluster-role` | secrets(get, list, watch), pods(get, list, watch)                                                 | `security-spec-group`               |
| **clients namespace:**                   |                                                                                                   |                               |
| ClusterRole `dev-ops-role-template`      | secrets(get, list, watch, create, update, delete), pods(get, list, watch, create, update, delete) | `clients-dev-ops-group`       |
| ClusterRole `ops-role-template`          | pods(get, list, watch, create, update, delete)                                                    | `clients-ops-group`           |
| ClusterRole `developers-role-template`   | pods(get, list, watch)                                                                            | `clients-developers-group`    |
| **tenant namespace:**                    |                                                                                                   |                               |
| ClusterRole `dev-ops-role-template`      | secrets(get, list, watch, create, update, delete), pods(get, list, watch, create, update, delete) | `tenant-dev-ops-group`        |
| ClusterRole `ops-role-template`          | pods(get, list, watch, create, update, delete)                                                    | `tenant-ops-group`            |
| ClusterRole `developers-role-template`   | pods(get, list, watch)                                                                            | `tenant-developers-group`     |
| **accountant namespace:**                |                                                                                                   |                               |
| ClusterRole `dev-ops-role-template`      | secrets(get, list, watch, create, update, delete), pods(get, list, watch, create, update, delete) | `accountant-dev-ops-group`    |
| ClusterRole `ops-role-template`          | pods(get, list, watch, create, update, delete)                                                    | `accountant-ops-group`        |
| ClusterRole `developers-role-template`   | pods(get, list, watch)                                                                            | `accountant-developers-group` |
| **data namespace:**                      |                                                                                                   |                               |
| ClusterRole `dev-ops-role-template`      | secrets(get, list, watch, create, update, delete), pods(get, list, watch, create, update, delete) | `data-dev-ops-group`          |
| ClusterRole `ops-role-template`          | pods(get, list, watch, create, update, delete)                                                    | `data-ops-group`              |
| ClusterRole `developers-role-template`   | pods(get, list, watch)                                                                            | `data-developers-group`       |
